# Mewarnai v1.0.0

Aplikasi mewarnai untuk anak. Ubah foto jadi sketsa, lalu warnai pakai krayon!

## ✨ Fitur
- 📷 Ambil foto dari kamera atau pilih dari galeri/SD card
- ✏️ Foto otomatis jadi sketsa garis siap diwarnai
- 🖍️ Warnai bebas dengan krayon — 12 warna + pemilih warna custom
- 📏 3 ukuran kuas (kecil, sedang, besar)
- 🔍 Cubit (pinch) untuk zoom & geser sketsa, lebih mudah warnai detail
- ↩️ Tombol Ulangi (undo) + simpan otomatis tiap 30 detik
- 🖼️ Galeri karya: lihat full screen, lanjut warnai, bagikan, hapus
- 🎵 Musik latar + tombol bisukan
- 🎨 Tampilan ceria ramah anak: tombol bouncy, krayon animasi, latar bergerak

## 📱 Perangkat
- Android 8.0+ (portrait)
